# CALCE protocol status

CALCE feature files are available for external feature-distribution audit. A full RUL comparison is not promoted to final evidence because the current CALCE ingestion does not yet have a locked, dataset-specific EOL threshold and censored-cell policy matching NASA/HUST. To make CALCE a formal external domain, freeze chemistry, cell inclusion, EOL definition, checkpoints, adaptation rule and untouched test cells before computing RUL metrics.
